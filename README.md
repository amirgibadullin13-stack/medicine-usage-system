# Система учёта использования препаратов (версия без дизайна)

Настольное приложение: WPF, .NET 10, SQLite. Работает только на Windows.

## Запуск из VS Code

```
dotnet restore
dotnet run
```

## Сборка в exe

Дважды щёлкните `publish.bat` (или выполните `publish.bat` в терминале). Готовый файл появится здесь:

```
publish\DrugUsageSimple.exe
```

Это один файл, его можно копировать на любой компьютер с Windows 10/11 x64 — .NET устанавливать не нужно.
Первая сборка скачивает пакеты и может занять несколько минут.

## Вход

При первом запуске создаётся администратор: логин `admin`, пароль `admin`. Сразу смените пароль
(«Сменить пароль» в главном меню или раздел «Пользователи»).

- 3 неверные попытки входа — программа закрывается.
- Администратор видит раздел «Пользователи»: список логинов и паролей, добавление пользователей,
  смена паролей, удаление.
- Обычный пользователь может сменить только свой пароль (нужно знать текущий).

## Что умеет

| Раздел | Возможности |
|---|---|
| Начать ввод | ФИО, дата рождения, отделение, дата исполнения; несколько строк препаратов — у каждой своя дата использования |
| Пациенты | Список, поиск по ФИО, редактирование, удаление |
| Отчёты | Период и отделение считаются по дате использования препарата; сортировка детального отчёта (по дате, по препарату, по ФИО); общий итог без ФИО; выгрузка в XLSX с фильтрами и сортировкой |
| Справочники | Отделения и препараты |
| Резервное копирование | Выгрузка базы в JSON и восстановление (заменить / объединить). Копии старой версии без дат подходят: дата берётся из даты исполнения |

База хранится в `%LocalAppData%\DrugUsageSimple\drugusagesimple.db`.
